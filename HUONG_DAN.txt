WEALTHFLOW - HUONG DAN KHOI DONG & QUAN LY HE THONG (TUI CONTROL CENTER)
========================================================================

1. KHOI DONG TRUC TIEP BANG 1 CLICK / 1 DONG LENH
------------------------------------------------------------------------
* Tren Windows:
  - Double-click `SETUP_SE.bat` de cai dat/khoi dong truc tiep; hoac
    double-click `CHAY_SE.bat` (ca hai se giu cua so mo de xem ket qua).
  - Khong double-click truc tiep `setup-se.ps1`; hay chay qua file `.bat`.
  - Cach khac: Double-click vao file `run_wealthflow.bat`.
  - Mo terminal PowerShell/CMD tai thu muc project, chay:
      .\run_wealthflow.bat

* Tren Linux / macOS:
  - Mo Terminal tai thu muc project va chay:
      chmod +x run_wealthflow.sh
      ./run_wealthflow.sh

2. GIAO DIEN DIEU KHIEN TRUCTIEP TREN TERMINAL (INTERACTIVE TUI MENU)
------------------------------------------------------------------------
Khi chay script, terminal se hien thi menu tuong tac truc quan:

  [1] Khoi dong he thong (Start Web + DB) va Mo trinh duyet
      -> Tu dong mo PHP Built-in Server (http://localhost:8070)
      -> Ket noi MariaDB dang chay trong XAMPP (Port 3306)
      -> Tu dong nap migrations chua ap dung va mo trinh duyet Web
  [2] Dung Web server
      -> Chi dung PHP server; de XAMPP MariaDB tiep tuc chay cho cac do an khac
  [3] Kiem tra trang thai chi tiet (Health Check & API status)
      -> Kiem tra port 8070, port 3306 va goi /api/health
  [4] Chay cap nhat CSDL Migrations (28 SQL files 001_ den 028_)
  [5] Reset CSDL & Du lieu mau (Reset & Seed sach se)
      -> Xoa & tao lai DB wealthflow, tai tao data demo
  [6] Chay bo kiem thu tu dong (36 unit tests + 7 mail smoke tests)
  [7] Xem nhat ky loi & email OTP gia lap (.eml) gan nhat
  [8] Mo trinh duyet Web (http://localhost:8070/)
  [0] Thoat (Exit)

3. CO CHE CO LAP AN TOAN (SAFE ISOLATION)
------------------------------------------------------------------------
- Script tu dong tim kiem thu muc XAMPP tren cac o dia (D:\xampp, C:\xampp, E:\xampp...).
- Su dung PHP Built-in Server (cong 8070) va MariaDB XAMPP (cong 3306).
- Hay bat MySQL trong XAMPP truoc khi chay setup. Setup khong tu tao DB server rieng.
- Setup chi tao/cap nhat schema database `wealthflow` tren MariaDB XAMPP.
- Du lieu cua do an nam trong database `wealthflow` (XAMPP quan ly trong `mysql\data`);
  khong tao MySQL server/datadir rieng va khong cham vao database cua do an khac.
